# Plan Guide (AgentTeams) — Index

> ⚠️ This file is automatically deployed from the server. Do not edit it directly.

Plan rules are split by the moment you need them. Writing a plan and running one are different jobs with different rules, and reading both at once costs context you need for the actual work. Open the one that matches what you are doing now.

| You are…                                                                         | Read                         |
| -------------------------------------------------------------------------------- | ---------------------------- |
| Drafting a new plan, or rewriting one at a higher complexity tier                | `plan-authoring-guide.md`    |
| Running a plan that already exists, tracking its tasks, or finishing it          | `plan-execution-guide.md`    |
| Recording work you already finished, with no plan for it yet (a **quick log**)   | `plan-execution-guide.md`    |
| Writing the completion report, or deciding on a co-action / post-mortem / review | `completion-report-guide.md` |

## Plan Body Templates

Copyable plan bodies, one per complexity tier. Take the one matching the `--complexity` you set at creation — do not copy a larger tier and delete sections.

| Tier       | Template                    |
| ---------- | --------------------------- |
| `MINIMAL`  | `plan-template-minimal.md`  |
| `STANDARD` | `plan-template-standard.md` |
| `FULL`     | `plan-template-full.md`     |

How to judge which tier applies is defined in `plan-authoring-guide.md` (**Plan Complexity**).
